# Italy Travel Page 🇮🇹

A simple HTML project showcasing travel destinations and packages across Italy.

## ✨ Features
- Travel packages (group & private)
- Top destinations: Rome, Bolzano, Naples
- Semantic HTML structure
- Clickable images with figure and figcaption

## 🛠️ Technologies
- HTML5

## 📚 About
This project was created as part of the Responsive Web Design Certification by freeCodeCamp.
